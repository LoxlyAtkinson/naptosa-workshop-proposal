# NAPTOSA connected network proposal

Self-authored under explicit creative delegation. The user directed the build, requested Higgsfield video, and said to proceed; the design decisions below are authored defaults, not user quotations.

## Eight creative topics

1. **Vibe and references:** Authored default: credible, warm, national, contemporary, clear. Use the existing NAPTOSA shield and navy/blue/gold identity. No outside reference site requested.
2. **Journey:** Open with educators and the national/provincial idea; explain how the network works; show workshop tasks; clarify the data choice and why the dedicated option has a fee; present transparent build and monthly totals; finish with delivery, terms, and approval/download.
3. **Energy curve:** Calm human opening; rising clarity through the network map; focused operational workshop explanation; decisive data-separation peak; calm, high-contrast price/acceptance ending.
4. **Feeling and peak:** Curious → oriented → confident → reassured → ready to decide. Peak visitor thought: “Each province can work independently, while national can still see the whole programme, and I can see exactly what that costs.” Peak lives in the data topology chapter.
5. **Signature move:** A scroll-controlled journey turns the proposal's data architecture into an instantly legible before/after diagram, then carries those exact offered rates into the quotation.
6. **Aesthetic range:** Editorial premium, approachable and restrained; prioritize readability for management readers and visual learners.
7. **Structure:** Distinct chapters, not an unbroken camera flight. Use a short scrub hero, then network reveal, workshop pan, data architecture reveal, pricing flow, and a clear acceptance close.
8. **Available assets:** NAPTOSA shield, current official proposal content and PDF, existing site asset collection. Hero still/video to be generated with the user's requested Higgsfield workflow. Icons and diagrams are custom inline SVG/CSS.

## Feeling curve

- Opening: welcome and curiosity, created by a documentary view into a teacher workshop.
- Network: orientation, created by a readable national hub and province map.
- Workshop: confidence, created by a four-step staff journey and itemized scope.
- Data: reassurance and a decision point, created by shared-versus-dedicated topology and focused R699→R499 callout.
- Investment: control, created by original prices, highlighted offered prices, totals, and savings.
- Close: readiness, created by delivery estimate, terms, signatures, and PDF download.
